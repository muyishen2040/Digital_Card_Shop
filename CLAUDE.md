# Claude Code project guidance

Follow [AGENTS.md](AGENTS.md) and the docs in `docs/`.

This repository is designed to use the upstream `obra/superpowers` plugin in Claude Code. Install via:

`/plugin install superpowers@claude-plugins-official`

Do not vendor Superpowers into this repository. Follow its brainstorming, planning, worktree, testing, and review skills when available.
